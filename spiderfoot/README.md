# SpiderFoot

## Objective

Automate passive OSINT collection about tesla.com.

## Modules Used

- sfp_whois
- sfp_crt
- sfp_dnsraw
- sfp_dnsresolve
- sfp_sslcert

## Results

- WHOIS information
- DNS records
- Nameservers
- Mail infrastructure
- DNS relationships
- SSL/TLS information

## Note

The scan was performed for educational purposes using passive reconnaissance techniques.
