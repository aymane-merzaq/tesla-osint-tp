# Tesla OSINT TP

## Objective

Collect publicly available information about tesla.com using passive OSINT techniques.

## Tools Used

- Recon-ng
- theHarvester
- SpiderFoot

## Information Collected

- WHOIS information
- IP addresses
- Hosts and subdomains
- DNS records
- Mail infrastructure
- SSL/TLS information

## Disclaimer

This project was conducted for educational purposes only.
